Angerona Nota is a small, local-only text editor for plain-text notes - no
accounts, no cloud sync, no ads, no tracking. Everything stays on your device.

Every file you save is encrypted with AES-256-GCM, using a non-exportable key
held in the Android Keystore. Only Angerona Nota, on this specific device, can
read it back. Older plain-text .txt files simply open as-is; an encrypted file
that can't be decrypted (missing key, corrupted or tampered with) shows a
warning instead of garbled text.

Features:
* New, Open, Save, Find & Replace, word wrap, optional line numbers
* Encrypted by default - no way to accidentally save in plain text
* English, French, and Spanish, following your phone's system language
* Warm, editorial "Classical" visual design - serif chrome, monospace editor
* No network permission requested. This app cannot phone home even if it
  wanted to.

A word of honesty: uninstalling the app, a factory reset, or moving to another
phone all lose the encryption key. Already-encrypted files then become
permanently unreadable - there is no password recovery. Please read the
"File encryption" section of the project README before trusting it with
anything you can't afford to lose.
